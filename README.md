# hey-test

A static test copy of the listener from `pflantzer-lab/apps/hey`, for trying the voice phrases on a phone before hey.pflantzer.com is deployed.

Open https://pflantzdog27.github.io/Hey-test/ in Safari (iPhone) or Chrome (Android), tap the microphone and say "Hey Claude", "Hey GPT", "Hey NYT" or "Hey Camera".

The maker is switched off here: it needs the server. Safe to delete once the real site is live.
